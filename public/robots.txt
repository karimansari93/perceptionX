# app.perceptionx.ai is the logged-in dashboard. Only the site root — the
# public sign-in / create-account page — belongs in a search index; every other
# route is behind sign-in or a link token.
#
# Crawling is allowed everywhere anyway, on purpose: what keeps those routes
# out of the index is the `noindex` in index.html's <head>, and a crawler
# blocked here can never read it. A Disallowed URL can still be indexed from an
# external link, and then there is no way to remove it.
#
# So: allow everything, and let the meta tag do the work. The one exception is
# the site root — the public sign-in / create-account page — which Netlify
# serves from home.html with `index, follow`. If another route is ever made
# public it needs its own pre-rendered variant (see META_VARIANTS in
# vite.config.ts) — not a rule here.
#
# The link-preview crawlers are named explicitly for the same reason: they
# respect Disallow and would otherwise render nothing at all for an /activate
# or /onboarding unfurl.
